# Менеджер задач педагога

Программный модуль для автоматизации учёта и контроля повседневных задач педагога МБОУ СОШ № 182.

## Описание

Модуль позволяет педагогу:
- Добавлять новые задачи с названием и описанием
- Просматривать список всех задач
- Отмечать задачи как выполненные
- Удалять задачи
- Очищать список выполненных задач
- Сохранять данные между сеансами работы

## Архитектура

Модуль реализован по принципу многоуровневой архитектуры с разделением ответственности:

- **`data_manager.py`** — компонент управления данными (чтение/запись JSON)
- **`task_logic.py`** — компонент бизнес-логики (обработка задач)
- **`ui_module.py`** — компонент пользовательского интерфейса (консольное меню)
- **`main.py`** — главный файл запуска

## Требования

- Python 3.8 или выше
- Операционная система: Windows 10/11, Linux
- Внешние зависимости: отсутствуют (используется только стандартная библиотека)
