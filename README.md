# Менеджер задач педагога

**Программный модуль для автоматизации учёта и контроля повседневных задач педагогического состава образовательного учреждения.**

---

## Описание

«Менеджер задач педагога» — это консольное приложение, разработанное для автоматизации рабочих процессов педагогов МБОУ СОШ № 182 г. Новосибирска. Модуль позволяет эффективно управлять перечнем повседневных задач, включая подготовку к урокам, проверку работ, проведение классных часов и взаимодействие с родителями.

### Основные возможности

- Добавление новых задач с названием и описанием
- Просмотр списка всех активных и выполненных задач
- Отметка задач как выполненных с сохранением истории
- Удаление отдельных задач или очистка списка выполненных
- Автоматическое сохранение данных между сеансами работы
- Обработка некорректного ввода данных пользователем

---

## Архитектура

Модуль реализован по принципу многоуровневой архитектуры с разделением ответственности (Separation of Concerns), что обеспечивает гибкость, тестируемость и удобство дальнейшего сопровождения.

### Структура проекта

    teacher-task-manager/
    ├── data_manager.py      # Компонент управления данными (чтение/запись JSON)
    ├── task_logic.py        # Компонент бизнес-логики (обработка задач)
    ├── ui_module.py         # Компонент пользовательского интерфейса (консольное меню)
    ├── main.py              # Главный файл запуска приложения
    ├── README.md            # Документация проекта
    └── tasks.json           # Файл хранения данных (создаётся автоматически)

### Взаимодействие компонентов

    ┌─────────────────────┐
    │   ui_module         │  ← Пользовательский интерфейс
    │   (ввод/вывод)      │
    └──────────┬──────────┘
               │ вызов функций
               ▼
    ┌─────────────────────┐
    │   task_logic        │  ← Бизнес-логика
    │  (обработка задач)  │
    └──────────┬──────────┘
               │ чтение/запись
               ▼
    ┌─────────────────────┐
    │   data_manager      │  ← Управление данными
    │ (работа с JSON)     │
    └──────────┬──────────┘
               │
               ▼
    ┌─────────────────────┐
    │  tasks.json         │  ← Файл хранения
    └─────────────────────┘

Такая архитектура позволяет в дальнейшем:
- Заменить компонент хранения (например, перейти на базу данных)
- Заменить компонент интерфейса (например, на графический интерфейс)
- Модифицировать бизнес-логику без влияния на другие компоненты

## Требования

### Системные требования

- Операционная система: Windows 10/11, Linux
- Процессор: не ниже Intel Celeron / AMD Athlon
- Оперативная память: не менее 2 ГБ
- Свободное дисковое пространство: не менее 10 МБ

### Программные требования

- Python: версия 3.8 или выше
- Внешние зависимости: отсутствуют (используется только стандартная библиотека Python: json, datetime, os)

## Установка и запуск

### Способ 1: Клонирование репозитория (рекомендуется)

    git clone https://github.com/bomjelita/teacher-task-manager.git
    cd teacher-task-manager
    python main.py

### Способ 2: Скачивание ZIP-архива

1. Нажмите кнопку "Code" → "Download ZIP"
2. Распакуйте архив в любую папку
3. Откройте терминал в папке проекта
4. Выполните команду: python main.py

### Способ 3: Ручная загрузка файлов

1. Скачайте все файлы из репозитория
2. Поместите их в одну папку
3. Запустите main.py через Python

## Использование

После запуска программы появится главное меню:

    === Менеджер задач педагога ===
    1. Добавить задачу
    2. Показать все задачи
    3. Отметить задачу как выполненную
    4. Удалить задачу
    5. Очистить список выполненных задач
    0. Выход

### Примеры использования

**Добавление задачи:**

    Выберите пункт меню: 1
    Введите название задачи: Подготовка к уроку
    Введите описание (можно пропустить): 7 класс, алгебра
    Задача 'Подготовка к уроку' добавлена!

**Просмотр списка задач:**

    Выберите пункт меню: 2

    Список задач:
    [1] Подготовка к уроку - Активная (2026-11-25 14:30)
    [2] Проверка контрольных работ - Активная (2026-11-25 15:00)

**Отметка задачи как выполненной:**

    Выберите пункт меню: 3
    Введите ID задачи: 1
    Задача отмечена как выполненная!
